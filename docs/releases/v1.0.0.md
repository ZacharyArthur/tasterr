## Security review

The full pre-v1.0 source tree passed review on 2026-07-13 against every applicable
checklist in `docs/SECURITY.md`: API/auth/session behavior, trusted proxies, outbound
HTTP boundaries, frontend rendering/storage, database access, dependencies/build,
workflows, logging, documentation, and source-controlled public-release controls.

Three findings were resolved with regressions before the pass: the browser fixture
supervisor was moved outside the production image's copied source tree, SQLAlchemy
exception output now hides bound parameters, and stable image tags must be exact
SemVer commits reachable from `main`. Repository-host settings such as private
vulnerability reporting, secret scanning/push protection, and Dependabot remain an
operator verification before tagging and are not claimed by this source-tree result.

A follow-up review made external Seerr networking optional for routable LAN
deployments, put invasive request cleanup on every post-create exit path, added
behavioral trusted-proxy CIDR coverage, removed a fulfilled deferral, and excluded
generated Playwright reports/results from repeat-run linting. The strict OpenSpec and
deterministic release gates passed after those corrections.

## Known limitations

- Tasterr v1.0 is a single-process household service; multiple workers are not
  supported.
- It does not bundle Seerr, play media, import Plex history, or provide native apps.
- Branch-protection settings are external repository administration and are not
  enforceable in source control.
- A non-failing upstream TestClient deprecation remains scheduled for a dependency
  maintenance change.

## Rollback basis

M6 adds no database migration. Roll back by selecting the preceding known-good image
digest and retaining the current SQLite volume. If rolling back across any earlier
schema-changing release, restore its validated pre-upgrade database backup first.
