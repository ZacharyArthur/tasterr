## Security review

The 2026-07-22 pre-publication review found and this change addresses the following
source-tree issues:

- Uvicorn request access logs disclosed complete search query strings.
- Application log templates carried stable household user and title identifiers.
- Responses exposed the Uvicorn server header and lacked CSP/frame, MIME-sniffing,
  referrer, permissions, and trusted-HTTPS-only HSTS policies.
- Compose published port 8000 on every host interface by default.
- The locked dev-only type-generator tree contained three high-severity audit
  findings.
- No explicit source license existed.

Focused regressions cover production server arguments, generic log templates, API/
SPA/static/error response headers, synthesized 500 responses, effective-HTTPS HSTS,
loopback and explicit-LAN Compose rendering, AGPL package/image declarations, and
the patched type-generator output. Strict OpenSpec validation and the focused
regressions passed on 2026-07-22. The final deterministic gate and browser/container
smoke also passed. An earlier review found an inaccurate React Router registry claim
and several evidence/test gaps; the correction migrates to the published v8 package,
exercises HSTS across the trusted-proxy boundary, aligns the live-suite waiver
procedure, and removes brittle evidence wording.

The initial `no-referrer` policy caused YouTube iframe error 153. On 2026-07-25 it
was corrected to `strict-origin-when-cross-origin`, which supplies YouTube only the
application origin while withholding title routes and query strings. Focused tests,
strict OpenSpec validation, a rebuilt healthy container, the actual container
header, and browser trailer playback passed after the correction. The
operator-supplied home, detail, and search screenshots were visually checked for
redaction, stripped of non-structural metadata, resized for the web, and linked from
the README. The README mark and browser tab use the same native favicon asset. Final
deterministic gates and strict OpenSpec validation passed after those assets landed.

Two independent final pre-publication reviews returned GO on 2026-07-25. One
reported three non-blocking documentation gaps: the final gate scope was
under-described, the published-image path did not explain where `.env` came from,
and the repository-creation wording could invite a premature push. The other
reported no findings. The documentation gaps were corrected by explicitly recording
the complete gate scope, distinguishing process environment from Compose
`env_file`, and forbidding any push before Actions is disabled.

## Known limitations

- Tasterr v1.0 is a single-process household service; multiple workers are not
  supported.
- It does not bundle Seerr, play media, import Plex history, or provide native apps.
- Branch protection and repository security settings are external administration
  and cannot be enforced by this source tree.
- A non-failing upstream TestClient deprecation remains scheduled for dependency
  maintenance.

## Rollback basis

This release-readiness change adds no database migration. Roll back by selecting the
preceding known-good image digest and retaining the current SQLite volume. If rolling
back across any earlier schema-changing release, restore its validated pre-upgrade
database backup first.
