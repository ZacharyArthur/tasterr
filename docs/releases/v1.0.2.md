# Tasterr v1.0.2 release evidence

- Release date: 2026-08-18
- Git tag: `v1.0.2`
- Evidence status: approved for release after the required pre-tag controls. The
  GitHub Release is the authoritative record for the final manifest digest,
  publication time, alias verification, and tagged-image smoke result.

## Scope

- Related-title navigation now stays within one detail-overlay history entry, the
  document behind the overlay no longer scrolls, and refreshed My List state no
  longer requires an extra click after reopening a title.
- Detail responses expose a server-generated TMDB reference rendered as an isolated
  external link. Focus remains trapped and predictable when related-title content
  replaces the active dialog.
- Contributor guidance, issue templates, and release-workflow safeguards merged
  after v1.0.1 are included in this patch release.
- Audited dependencies were patched where compatible: `cryptography` 50.0.0,
  `brace-expansion` 2.1.4, `nanoid` 3.3.18, and `undici` 7.29.0.
- The release adds no database migration, configuration change, dependency, or new
  outbound request.

## Completed verification

- Final `just release-check` passed on 2026-08-18 with 446 backend tests and 68
  frontend tests, generated API type freshness, lint and strict type checks, the
  production frontend build, the Chromium login/home/detail/request journey, and
  native container health, private logs, hardened headers, SPA serving, non-root
  runtime, and volume persistence.
- OpenSpec change `fix-detail-feedback` passed strict validation with all 20 tasks
  complete, synced two requirements into the living `media-browse` specification,
  and was archived as `2026-08-19-fix-detail-feedback` before merge.
- Multiple complete working-tree reviews reported no blocking findings. The final
  optional focus-trap test was added so both Tab directions from programmatic dialog
  focus are directly asserted.

## Dependency audit

- `pip-audit` reported no known vulnerabilities after upgrading `cryptography` to
  50.0.0. The local Tasterr package was skipped because it is not a PyPI
  distribution.
- `npm audit --omit=dev` reported no known vulnerabilities after the compatible
  transitive patches.
- Full `npm audit` reports three high-severity nodes in one development-only chain:
  [`GHSA-5p4m-2wfm-xmqj`](https://github.com/advisories/GHSA-5p4m-2wfm-xmqj)
  affects `js-yaml` 4.3.0 through Redocly and `openapi-typescript`. The tool processes
  only the repository-generated OpenAPI schema during development/build and is
  absent from the runtime image. The latest compatible `openapi-typescript` release
  still selects the affected Redocly line; forcing the `js-yaml` 5 major override
  was rejected. Upgrade when the generator supports a patched compatible version.

## Security review

- The complete diff since v1.0.1 was reviewed. No auth/session, Seerr client,
  mutation, database, trusted-proxy, logging, or runtime outbound-HTTP boundary
  changed.
- The TMDB link is constructed by the backend from a fixed HTTPS origin, validated
  media type, and numeric identifier. No upstream URL or secret reaches the client,
  and the browser link prevents opener access.
- Public repository controls were verified: private vulnerability reporting,
  Dependabot alerts/security updates, secret scanning, push protection, protected
  squash-only `main`, required checks, immutable `v*` tags, artifact attestations,
  and immutable GitHub Releases are enabled.
- Repository fixtures and release records contain invented local placeholders only;
  no live credentials, household identities, internal URLs, or generated failure
  artifacts are included.

## Live-contract disposition

The release owner waives another live Seerr run. The complete Seerr 3.3.0 baseline
from 2026-07-13 passed ten cases with no skips, and this release does not change
Seerr clients, authentication/session behavior, request/availability contracts, or
the live harness.

## Known limitations

- Browser-level long-detail scrolling, direct-detail Close then browser Back, and
  stable scrollbar-gutter coverage remain tracked in `docs/DEFERRED.md`.
- Tasterr v1.0 remains a single-process household service; multiple workers are not
  supported.
- It does not bundle Seerr, play media, import Plex history, or provide native apps.
- A non-failing TestClient deprecation remains scheduled for dependency maintenance.
